# Performance & Scaling Backlog (`nox-decomp-3ds`)

This folder tracks the prioritized performance, hardware-utilization, memory-bandwidth, and UI/FOV scaling findings audited across the decompiled engine (`src/`), the New 3DS backend (`port/3ds/`), and compiled ARM11 ELF output (`build-3ds/nox.elf`).

> **Status Note (2026-11-26):** The combined [`v0.3.0-3ds-all-stacked`](https://github.com/fungusshark/nox-decomp-3ds/releases/tag/v0.3.0-3ds-all-stacked) performance stack (`feat/all-stacked`) was backed out of `main` back to pre-stack `87ba9d5` after real-3DS hardware testing surfaced rendering, menu column, touchscreen, and stability regressions. All 12 individual `feat/*` branches remain unmerged for isolated real-hardware A/B profiling, while historical backlog issues remain archived as ([#16](https://github.com/fungusshark/nox-decomp-3ds/issues/16)–[#27](https://github.com/fungusshark/nox-decomp-3ds/issues/27)) and active bugs are tracked in [GitHub Issues](https://github.com/fungusshark/nox-decomp-3ds/issues).
