# Performance & Scaling Backlog (`nox-decomp-3ds`)

This folder tracks the prioritized performance, hardware-utilization, memory-bandwidth, and UI/FOV scaling findings audited across the decompiled engine (`src/`), the New 3DS backend (`port/3ds/`), and compiled ARM11 ELF output (`build-3ds/nox.elf`).

> **Status Note (2026-11-26):** **`v0.2.7-3ds-hwfix`** (`c35694c` on `main`) fixed the real-3DS VBlank phase lock and runs cleanly at **30 FPS** on hardware. The combined [`v0.3.0-3ds-all-stacked`](https://github.com/fungusshark/nox-decomp-3ds/releases/tag/v0.3.0-3ds-all-stacked) bundle (`feat/all-stacked`) and all broken/tainted/superseded `v0.3.0` feature branches (**`#01, #02, #04–#09, #11, #12`**) have been documented with post-mortems on GitHub Issues [#16](https://github.com/fungusshark/nox-decomp-3ds/issues/16)–[#28](https://github.com/fungusshark/nox-decomp-3ds/issues/28) and **deleted/abandoned so they are not re-attempted**. Only `#03` (`feat/perf-anticheat-and-vis`) and `#10` (`feat/perf-font-minimap-cursor`) remain parked on the side unmerged as low-risk experimental candidates, while active bugs are tracked in [GitHub Issues](https://github.com/fungusshark/nox-decomp-3ds/issues).

## Git Workflow & CI

* **[../docs/3DS_HARDWARE_LEARNINGS.md](../docs/3DS_HARDWARE_LEARNINGS.md)** — Consolidated real-3DS hardware findings (dual-LCD `VBlank0`/`VBlank1` phase offset, ARM11 alignment & `VFPv2` traps, PICA200 cache coherency, Horizon OS Wi-Fi/SDMC stalls, and touch/dialog lessons).
